# PT. Karya Pratama Konsulindo — Landing Page

Landing page company profile modern/minimalis yang dibuat dari materi `COMPANY PROFILE TERBARU JUNI 2026_compressed.pdf`.

## Struktur

- `index.html` — halaman utama
- `css/style.css` — seluruh styling
- `js/main.js` — mobile menu, scroll reveal, back-to-top, lightbox
- `assets/images/` — gambar yang sudah dioptimasi ke WebP
- `assets/documents/company-profile.pdf` — PDF company profile sumber

## Cara menjalankan

Bisa dibuka langsung dengan `index.html`, atau dijalankan lewat local server sederhana.

```bash
python -m http.server 8080
```

Lalu buka `http://localhost:8080`.
